Keep your Quake II server clean

Q2Admin loads between the server and your mod, and adds the admin tools and anti-cheat Quake II never shipped with. It works with deathmatch, CTF, OpenTDM, Action, Rocket Arena 2, Jump and anything else, without changing the mod.

Install Q2Admin Read the documentation

How it works

A Quake II server runs its gameplay from a game library, such as gamex86_64.so. Q2Admin is a game library too. The server loads Q2Admin, and Q2Admin loads your real mod and passes every call through.

Quake II serverQ2Pro, R1Q2, Yamagi Quake II or the original.
Q2AdminSees every connection, command, chat line, movement packet and map entity. Blocks, filters, probes and logs before passing them on.
Your modRenamed to gamex86_64.real.so and left untouched.

What it adds

Catch cheaters

Proxy and client checks
Randomized probes that zbot, ratbot and hacked clients answer wrong.
Aim analysis
Spots bot jitter, silent-aim snaps and inhumanly steady tracking.
Speed hacks
Flags players who use more game time than the clock allows.
Signal scores
Adds up suspicious events, so you act on patterns, not single hits.
VPN detection
Flags VPN and hosting addresses, so kicked players can't just come back.

Keep order

Bans
By name, IP or range, timed or permanent, with lists shared between servers.
Flood control
Limits chat, name changes, skin changes and connection floods.
Mute and chat filters
Silence or filter players without kicking them.
Client settings
Requires allowed values for client cvars and blocks mod commands you don't want used.

Run the server

Voting
Players vote on commands you allow, even in mods with no voting.
Limited rcon
Moderators get only the commands you choose.
Logs
Connections, chat, kicks, bans and detections in separate files.
Modern engines
IPv6, variable frame rates and Q2Pro demo recording.

Install

  1. Build Q2Admin for your platform. The server, Q2Admin and the mod must all be 32-bit or all 64-bit.
  2. Rename your mod, for example to gamex86_64.real.so, or set gamelibrary in q2admin.cfg.
  3. Put Q2Admin in the mod folder under the name the server loads, such as opentdm/gamex86_64.so.
  4. Copy the example configs from runtime-config and edit q2admin.cfg.
  5. Start the server. Q2Admin prints its version as it loads.

Build on Linux

git clone https://github.com/packetflinger/q2admin
cd q2admin
make

On x86_64 and arm64 every library is bundled, so a compiler is all you need. Windows builds use MinGW and macOS builds use Homebrew. Build instructions

Run an admin command

sv !kick CL 3
rcon mypassword sv !mute claire 60

Twenty-plus years on Quake II servers

Late 1990s

The original

Shane Powell (KillerBee) wrote Q2Admin as a drop-in proxy mod to fight the zbot and ratbot aim proxies spreading through Quake II servers.

2000s

Community fixes

Richard Stanway (R1CH), author of the R1Q2 engine, fixed bugs. Mars contributed source changes, and fixes from q2mods.org were folded in.

2007–2008

q2admin.net

MDVz0r and Jasper of z0r.nl released versions 1.17.45 to 1.17.52. They added shared remote ban lists, global exception lists for R1CH's anticheat, nick registration, and ready-to-run server installers for Action Quake 2 and OSP Tourney. Hifi helped with support and debugging, and everyone met in #q2admin on QuakeNet.

Today

PacketFlinger

PacketFlinger maintains Q2Admin on GitHub, adding 64-bit and arm64 builds, aim analysis, VPN detection, signal scoring, IPv6 and Cloud Admin for running many servers at once (in development). Thanks to every contributor.
