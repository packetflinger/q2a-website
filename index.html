Quake II server administration

Admin tools and anti-cheat
for any Quake II mod.

Q2Admin sits between your Quake II server and the game mod you run, such as deathmatch, CTF, OpenTDM, Action, Rocket Arena 2 or Jump. It adds cheat detection, bans, flood control, voting and logging without changing a line of the mod.

How it works

A Quake II server runs its gameplay from a game library, such as gamex86_64.so or gamex86.dll. Q2Admin is a game library too. The engine loads q2admin, and q2admin loads the real mod and forwards every call to it.

Every connection, command, chat line, movement packet and map entity passes through q2admin on its way to the mod, so it can inspect, filter or block any of them.

Features

Quake II came out in 1997, and most mods were written with no thought for hostile players. Q2Admin fills those gaps in one place, for every mod.

Proxy & modified-client detection

Sends randomized probe commands to each client. Genuine clients answer predictably; aim proxies like zbot and ratbot, and hacked clients, don't.

Aim analysis

Watches view angles between movement packets to spot bot jitter, silent-aim snap-fire and inhumanly steady tracking.

Speed-hack detection

Totals the game time each player uses over a window and flags clients that overrun or bank time to spend later.

Signals & scoring

Suspicious events add weighted points to a player's score, so you can act on patterns instead of single hits.

Bans & chat bans

Ban by name, IP or range, permanently or for a time. Ban lists can include files or remote URLs shared across servers.

VPN detection

Background lookups flag players on VPN or hosting addresses, so you can score, limit or block them.

Flood & abuse control

Limits for chat, name and skin changes and connection floods, plus mute, stifle and chat filtering.

Client variable enforcement

Require exact values or ranges for client cvars, and disable mod commands players shouldn't use.

Voting

Let players vote on any command you allow, even in mods that have no voting of their own.

Limited rcon

Give moderators passwords that run only the commands you choose, not the full rcon password.

Logging

Write connections, chat, kicks, bans and detections to separate, custom-formatted log files.

Engine aware

Negotiates features with modern engines like Q2Pro and R1Q2: IPv6, variable frame rates, extra userinfo and MVD recording.

Every option and command is documented in the README.

Quick start

  1. Build q2admin for your platform. The server, q2admin and the mod must share an architecture (64-bit with 64-bit).
  2. Rename the real mod library, for example to gamex86_64.real.so, or point to it with gamelibrary in q2admin.cfg.
  3. Install q2admin in the mod directory under the name the engine loads, for example opentdm/gamex86_64.so.
  4. Copy the example configs from runtime-config/ and edit q2admin.cfg.
  5. Start the server. Q2Admin prints its version and the features it negotiated.

Build on Linux

git clone https://github.com/packetflinger/q2admin
cd q2admin
make
make strip   # optional

On x86_64 and arm64, all libraries are bundled, so you only need a compiler. Windows DLLs cross-compile with MinGW (make CONFIG_WINDOWS=1), and macOS builds use Homebrew libraries. See Compiling.

Run admin commands

sv !kick CL 3
rcon mypassword sv !mute claire 60

History

Q2Admin has protected Quake II servers for more than two decades and has passed through several sets of hands.

  • Late 1990s

    The original

    Shane Powell (KillerBee) created Q2Admin as a drop-in proxy mod to fight the zbot and ratbot aim proxies spreading through Quake II servers.

  • Early 2000s

    Community fixes

    Richard Stanway (R1CH), author of the R1Q2 engine, fixed bugs, and Mars contributed source changes. Fixes from q2mods.org were folded in later.

  • 2007 – 2008

    q2admin.net

    MDVz0r and Jasper of z0r.nl released versions 1.17.45 to 1.17.52 from q2admin.net. They added a shared remote ban list, global exception and required lists for R1CH's anticheat, nick registration, and ready-to-run server installers for Action Quake 2 and OSP Tourney. Hifi helped with support and debugging, and the project was coordinated in #q2admin on QuakeNet.

  • Today

    PacketFlinger

    Q2Admin is maintained on GitHub by PacketFlinger, with 64-bit and arm64 builds, aim analysis, VPN detection, signal scoring, IPv6, and Cloud Admin for managing groups of servers (in development).
